# Длинные нарды

Партия на двоих по ссылке, с видеосвязью. Один файл `index.html`, без сервера: соединение напрямую между телефонами (WebRTC через PeerJS).

- Создайте игру → отправьте ссылку → соперник открывает её в Safari и разрешает камеру.
- Сделанный ход не отменяется, даже если сыгран один кубик из двух.
- Эмоции поверх экрана, включая свою картинку с телефона.
- Игра с ботом: Новичок, Любитель, Мастер, Гроссмейстер. Бот считает в фоновом потоке, партия сохраняется.

Свой TURN-сервер (если видео не соединяется через мобильный интернет): добавьте к ссылке `?tn=turn:ВАШ_ХОСТ:3478&tu=ЛОГИН&tp=ПАРОЛЬ`.

## Исходники

Папка `dev/`: `src/engine.js` — правила, `src/app.html` — интерфейс. `src/bot.js` — бот. Сборка: `cd dev && npm i && npm run build && npm test`. Турнир уровней: `N=100 node test/bot.test.js`.
